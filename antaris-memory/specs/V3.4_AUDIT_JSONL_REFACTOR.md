## 2. Refactor `_audit` Method

Replace the existing `_audit` method in `shared.py`:

```python
def _audit(self, action: str, agent_id: str, detail: str = "") -> None:
    from .locking import FileLock

    entry = {
        "timestamp": datetime.now().isoformat(),
        "action": action,
        "agent_id": agent_id,
        "detail": detail,
    }
    # Fast append-only write (O(1) instead of O(N) Read-Modify-Write)
    with FileLock(self.audit_path, timeout=10.0):
        with open(self.audit_path, "a", encoding="utf-8") as f:
            f.write(json.dumps(entry, separators=(',', ':')) + "\n")
            f.flush()
            try:
                os.fsync(f.fileno())
            except OSError:
                pass
```

## 3. Add Log Reader Helper

```python
def get_audit_log(self, limit: int = 500) -> List[Dict]:
    """Read the most recent audit logs efficiently from the .jsonl file."""
    if not os.path.exists(self.audit_path):
        return []

    logs = []
    from .locking import FileLock
    with FileLock(self.audit_path, timeout=10.0):
        with open(self.audit_path, "r", encoding="utf-8") as f:
            lines = f.readlines()
            for line in lines[-limit:]:
                if line.strip():
                    try:
                        logs.append(json.loads(line))
                    except json.JSONDecodeError:
                        continue
    return logs
```

## Why This Is Better at Scale

- **No parsing overhead** — No more deserializing the entire array just to append one event
- **Reduced lock contention** — Lock held for µs (string append) instead of ms (parse + serialize)
- **Crash resilience** — A mid-write crash corrupts only one line, not the entire array
